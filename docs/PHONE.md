# 폰·태블릿에서 쓰기 (Android, iPad, iPhone)

앱 주소: `https://juhyunyoo7-stack.github.io/mangareader/` (GitHub Pages, 2026-11-06에 응답 200 확인). 앱 코드에는 만화가 들어 있지 않고, 만화는 각 기기 브라우저 안에만 저장됩니다.

주의: 2026-11-06 점검에서 고친 내용(아래 "알려진 한계"의 수정 항목)은 로컬 커밋만 되어 있고 아직 이 주소에 올라가지 않았습니다. 재배포는 유도사님 승인 후 진행합니다.

## Android (Chrome)
1. Chrome에서 앱 주소를 엽니다.
2. 메뉴(⋮) > **앱 설치**(또는 "홈 화면에 추가")를 누릅니다. 설치형으로 쓰면 저장소가 지워질 위험이 줄어듭니다.
3. **책 가져오기**로 만화 파일(CBZ, ZIP, CBR, CB7, PDF, EPUB)이나 이미지 여러 장을 고릅니다. 이미지가 폴더째 있으면 **이미지 폴더 가져오기**를 씁니다.
4. 다른 앱(파일 관리자 등)에서 만화 파일을 **공유 > 만화 리더**로 보내도 가져와집니다(설치한 경우).
5. 뒤로 버튼: 책을 닫은 뒤 뒤로 버튼을 누르면 라이브러리로 갑니다(닫은 책이 다시 열리지 않음).

## iPad / iPhone (Safari)
1. Safari에서 앱 주소를 엽니다.
2. 공유 버튼 > **홈 화면에 추가**를 누르고, 홈 화면 아이콘으로 실행합니다. 홈 화면에 추가하지 않고 Safari 탭으로만 쓰면, Safari가 오래 안 쓴 사이트의 저장소를 지울 수 있습니다(ITP 7일 규칙). 만화를 오래 보관하려면 꼭 홈 화면에 추가하세요.
3. **책 가져오기**를 누르면 "사진 보관함 / 파일 선택" 메뉴가 나옵니다. 다운로드한 만화는 보통 **파일 선택**(파일 앱)에 있습니다. 이미지 여러 장을 한꺼번에 고르면 책 한 권이 됩니다.
4. **폴더 고르기는 iPadOS/iOS 18.4 이상에서만** 됩니다. 그보다 낮은 버전(예: iPadOS 17)에서는 **이미지 폴더 가져오기** 버튼이 보이지 않고, 대신 "책 가져오기에서 이미지를 모두 고르라"는 안내가 나옵니다.
5. 읽는 동안 화면이 꺼지지 않습니다(화면 켜짐 유지: Safari 16.4 이상, Chrome).

## PC와 폰 사이에서 읽던 쪽 옮기기
PC 런처(`localhost:4173`)와 폰 주소는 서로 다른 저장소입니다. 책 파일은 각 기기에서 따로 가져와야 하고, 진행률·북마크·읽기 설정만 아래처럼 옮깁니다.
1. 보내는 쪽: **설정 > 상태 내보내기**. PC·Android는 `mangareader-state-날짜.json` 파일이 다운로드됩니다. iPad·iPhone은 공유 창이 열리므로 **파일에 저장**, AirDrop, 메일 중 하나를 고릅니다.
2. 그 파일을 받는 기기로 옮깁니다(메일, 메신저, 클라우드, USB 등).
3. 받는 쪽: **설정 > 상태 가져오기**로 그 파일을 고릅니다. 이미 있는 책은 바로 반영되고, 아직 없는 책은 나중에 그 책을 가져올 때 자동으로 반영됩니다(같은 파일이면 내용으로 알아봄). 두 기기 기록이 다르면 최신 것이 이깁니다.

## 알려진 한계 (실기기 미검증 포함)
- 이 내용은 PC의 Playwright 에뮬레이션(Chromium "Pixel 7", WebKit "iPad Pro 11")과 코드 확인으로 점검했습니다. **실제 Android 폰·iPad·iPhone에서는 아직 확인하지 못했습니다.**
- PDF: 2026-11-06 수정 전 버전은 PDF 엔진(pdf.js 최신판)이 2026년에야 브라우저에 들어온 기능(`Map.getOrInsertComputed` 등)을 바로 써서 iPadOS 17/18에서 PDF가 열리지 않았을 가능성이 큽니다. 수정판은 구형 브라우저용 pdf.js(legacy)로 바꿨습니다. 재배포 전까지는 iPad에서 PDF 대신 CBZ를 권합니다.
- 큰 파일: CBZ/ZIP은 필요한 부분만 읽어서 큰 파일도 괜찮습니다. 낱장 이미지는 (수정판에서) 1 MB씩 바로 저장소에 기록합니다. PDF는 (수정판에서) 1 MB 단위로 필요한 부분만 읽습니다. **CBR(RAR)·CB7(7z)은 파일 전체를 메모리에 올리므로** iPhone 300 MB, iPad 600 MB, Android 400 MB~1 GB가 상한이고, 더 크면 "CBZ로 변환" 안내가 나옵니다. 큰 RAR는 PC에서 CBZ로 바꿔 옮기세요.
- 아주 큰 쪽(수천만 화소)은 iPhone/iPad에서 디코딩이 거부되면 해상도를 낮춰 다시 시도합니다.
- 전체 화면 버튼(`f` 키)은 iPhone Safari에 없는 기능입니다. 홈 화면 앱으로 실행하면 주소창 없이 보입니다.

## 다시 배포하는 방법 (참고, 승인 후)
1. `npm run build` 후 `dist/` 내용을 `gh-pages` 브랜치로 올립니다.
2. 푸시는 `git -c credential.helper= -c credential.helper='!gh auth git-credential' push` 형식 (기본 자격증명 창이 멈추는 문제 회피).
3. 설치된 앱은 다음에 앞으로 가져올 때(최대 1시간 간격) 새 버전을 확인하고, 라이브러리 화면에 "새 버전이 준비되었습니다" 안내와 **새로고침하여 업데이트** 버튼이 나옵니다.

## 주의
- 앱 주소가 바뀌면 브라우저 저장소(만화 목록)가 새 주소 기준으로 비어 보입니다.
