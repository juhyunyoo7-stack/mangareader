# MangaReader

오프라인 우선(offline-first) 만화/코믹 리더 PWA입니다. CBZ/ZIP 파일을 브라우저 안에서 직접 읽으며, 서버나 계정이 필요 없습니다. 모든 데이터는 사용 중인 기기에만 저장됩니다.

## 사용 방법 (설치 없이 바로 읽기)

1. 바탕화면의 **만화 리더** 아이콘을 두 번 클릭합니다.
2. 만화 리더 창이 열리면 **책 가져오기**를 눌러 만화 파일(CBZ, ZIP, CBR, CB7, PDF, 그림 EPUB)을 고르거나, 파일을 창 안으로 끌어다 놓습니다.
   - **낱장 이미지 파일**(JPG, PNG, WebP 등)도 됩니다. **책 가져오기**에서 이미지를 여러 장 한꺼번에 고르면 책 한 권으로 묶이고, 쪽 순서는 파일 이름의 숫자 순서(2 다음 10)입니다. 책 제목은 파일 이름의 공통 부분으로 정해집니다.
   - 이미지가 폴더 안에 있으면 **이미지 폴더 가져오기**로 폴더를 고르세요. 폴더 하나가 책 한 권이 되고 제목은 폴더 이름입니다. 하위 폴더가 있으면 폴더마다 한 권씩 만들어집니다.
3. 책 표지를 누르면 읽기가 시작됩니다. 왼쪽/오른쪽 화살표 키(또는 화면 왼쪽/오른쪽 클릭)로 쪽을 넘기고, `+`/`-` 키나 Ctrl+마우스 휠로 확대합니다(`0` 키는 원래 크기). 화면 가운데를 누르면 메뉴가 나옵니다.
4. 다 읽었으면 창을 닫으면 됩니다. 읽던 쪽은 자동으로 기억됩니다.

알아 두실 점

- 아이콘을 다시 눌러도 창이 하나 더 생기지 않고, 이미 열린 창이 앞으로 나옵니다.
- "4173번 포트를 쓰고 있습니다"라는 안내가 나오면 다른 프로그램(개발용 서버 등)을 닫고 다시 실행하세요. 만화책 목록이 이 주소에 저장되어 있어 다른 번호로 바꿀 수 없습니다.
- 가져온 만화는 이 컴퓨터 안(만화 리더 전용 Edge 프로필)에만 저장되고, 인터넷으로 보내지지 않습니다.
- "가이드 보기"(컷 단위로 확대)는 **실험 기능**입니다. 실제 만화에서는 컷을 잘못 나눌 때가 많아 기본으로 꺼져 있습니다.
- 바탕화면 아이콘은 `release\MangaReader.exe`를 가리킵니다. 프로그램 폴더를 옮기면 아이콘을 다시 만들어야 합니다.

## 폰에서 쓰기

폰(Android Chrome, iPhone Safari)에서는 설치형 웹앱으로 씁니다. 폰에 만화를 넣는 방법은 PC와 같습니다. **책 가져오기**에서 폰 안의 만화 파일이나 이미지 여러 장을 고르면 됩니다. 만화는 그 폰 안에만 저장되고 인터넷으로 보내지지 않습니다.

- 폰은 주소창에 앱 주소를 열어야 하므로, 앱을 인터넷 주소(HTTPS)에 올려야 합니다. 공개 배포는 유도사님 승인 후에 진행합니다. 배포 방법은 `docs/PHONE.md`에 있습니다.
- PC와 폰의 읽던 쪽은 자동으로 이어지지 않습니다. 설정 화면의 **상태 내보내기/가져오기**로 옮깁니다.

## 주요 기능

- CBZ/ZIP 가져오기 (파일 선택, 드래그 앤 드롭, Android 공유 대상). 같은 파일은 내용 키(contentKey)로 중복 방지
- 페이지 보기: 단일/양면/자동/웹툰, 좌우(LTR/RTL)·세로 방향, 표지 오프셋, 페이지별 예외 지정
- 확대/이동, 핀치 줌, 더블 탭, 키보드·휠 조작, 썸네일 스트립, 슬라이더
- 라이브러리: 시리즈 자동 묶음, 표지, 이어 읽기, 검색, 정렬
- 데스크톱 Chromium: 폴더를 연결해 복사 없이 제자리에서 읽기 (File System Access API)
- 저장 공간 관리: 읽은 책 파일만 삭제(진행률 유지) 후 재가져오기 시 자동 재연결, 전체 삭제(2단계 확인)
- 상태 내보내기/가져오기(JSON): 진행률·북마크·읽기 설정을 기기 간 병합(최신 우선). 14일간 백업이 없으면 알림
- 오프라인 동작 (자체 Service Worker, 빌드 시 프리캐시)

지원 형식: CBZ/ZIP, CBR/RAR, CB7/7z, PDF, 그림 위주 EPUB (검증 범위와 한계는 docs/STATUS.md 참고. 압축된 실제 RAR 파일은 아직 검증하지 못했습니다).

## 개발

```bash
npm install
npm run dev          # 개발 서버
npm run build        # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview      # 빌드 결과 미리보기 (포트 4173)
PW_PORT=15173 npm run check   # 윈도우가 4173을 예약해 EACCES가 나면 테스트 포트를 바꿔서 실행
npm test             # 단위 테스트 (Vitest)
npm run e2e          # E2E 테스트 (Playwright, 빌드 포함)
npm run check        # 타입 검사 + prettier + 단위 + 빌드 + E2E 전체
npm run format       # prettier 적용
npm run build:exe    # 데스크톱 실행 파일 release\MangaReader.exe + release\app (launcher/BUILD.md)
```

테스트용 CBZ 픽스처는 결정적으로 생성됩니다 (`npm run fixtures`, 코드: `scripts/fixtures`).
화면 캡처는 `SHOTS=1 npx playwright test screenshots --project=chromium-desktop` 으로 `docs/screenshots/` 에 다시 만들 수 있습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/core` | 순수 로직: 타입, 펼침면(spread) 엔진, 병합(syncMerge), 타일링, 메모리 예산 |
| `src/archive` | ZIP 리더(지연 읽기), 형식 판별, 이미지 프로브 |
| `src/data` | IndexedDB, OPFS, 가져오기, 폴더 연결(fsa), 백업(backup) |
| `src/engine` | 캔버스 렌더러, 제스처, 디코드 워커 클라이언트, 페이지 캐시 |
| `src/app` | Preact UI (라이브러리, 리더, 설정) |
| `docs/DESIGN.md` | 설계 문서, `docs/STATUS.md` 진행 현황 |

## 알려진 한계

- 실제 iOS/Android 기기에서의 검증은 아직 하지 못했습니다 (docs/STATUS.md 참고). Playwright WebKit(Windows)은 OPFS 쓰기가 되지 않아 저장 관련 E2E는 Chromium에서만 실행됩니다.
- UI는 한국어가 기본이며 설정에서 언어를 바꿀 수 있습니다 (`src/i18n/`).
- 아직 배포하지 않았습니다.
